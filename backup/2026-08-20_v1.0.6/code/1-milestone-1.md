## ✅ چه چیزهایی ساخته شد

### ۱. محیط و ابزار
- نصب **Go 1.22.12**
- راه‌اندازی ماژول `khan`
- نصب وابستگی‌ها: chi (روتر)، gorilla/websocket، x/crypto (Argon2id)، kardianos/service

### ۲. تنظیمات (config)
- پورت پیش‌فرض **۱۷۲۷** (بازه مجاز ۱۷۰۰-۱۷۹۹)
- `address_type: "ip" | "dns"` — IP یا DNS قابل تنظیم
- امنیت (روزهای انقضای توکن، قفل ورود)
- بکاپ خودکار
- تولید خودکار کلید رمزنگاری در اولین اجرا

### ۳. مدل‌ها (models)
- **۳ نقش:** کاربر (`user`) / سوپروایزر (`sup`) / ادمین (`adm`)
- کاربر با فیلدهای: هش رمز، مخفی، فعال، اجبار تغییر رمز
- اتاق: DM / گروه / عمومی / خصوصی
- پیام + فایل + واکنش + نشست

### ۴. دیتابیس (JSON سبک)
- جایگزین SQLite (محدودیت RAM در محیط بیلد)
- فایل واحد `khan.db.json`
- نوشتن اتمیک (tmp → rename)
- ۷ جدول: users, rooms, room_members, messages, reactions, sessions, files
- بکاپ = کپی فایل

### ۵. امنیت
- **Argon2id** برای هش رمز (پارامترهای استاندارد)
- **AES-256-GCM** برای رمزنگاری پیام‌ها (هر پیام IV جدا)
- توکن نشست ۳۲ بایتی تصادفی، انقضای ۷ روز
- تولید خودکار کلید رمزنگاری

### ۶. لایسنس (Ed25519)
- **بدون لایسنس:** ۲۰ کاربر رایگان
- **لایسنس معتبر:** ۵۰/۱۰۰/۵۰۰/∞ (طبق فایل)
- **لایسنس دستکاری‌شده:** ۵ کاربر (جریمه)
- فیلدهای مبهم: `m_u` به‌جای max_users
- کلید عمومی داخل باینری، کلید خصوصی پیش سازنده
- **ابزار gen-license:** تولید کلید + امضا + خروجی Go

### ۷. APIها (REST)
- ✅ ورود/خروج/تغییر رمز/من
- ✅ کاربران: لیست/جستجو/ساخت/حذف/ریست رمز/فعال‌سازی/نقش
- ✅ اتاق‌ها: لیست/ساخت/عضویت/اعضا/تغییر نام/DM
- ✅ پیام‌ها: تاریخچه/ویرایش/حذف/واکنش
- ✅ فایل‌ها: آپلود/دانلود (رمزنگاری‌شده)
- ✅ تنظیمات: اطلاعات/لایسنس/شبکه
- ✅ نصب اولیه: needs-setup/setup

### ۸. WebSocket (زنده)
- Hub برای مدیریت اتصال‌ها
- رویدادها: پیام، ویرایش، حذف، واکنش، تایپینگ، حضور (آنلاین/آفلاین)
- پشتیبانی از چند کاربر همزمان

## 🐛 باگ پیدا و رفع شد

**مشکل:** اتصال WebSocket با خطای 401 ناموفق بود
**علت:** مسیر `/ws` داخل middleware احراز هویت قرار داشت که فقط هدر Authorization را می‌خواند، ولی کلاینت توکن را در query string می‌فرستاد
**راه‌حل:** `/ws` از گروه middleware خارج شد — خود ws_handler توکن را از query یا هدر چک می‌کند
**نتیجه:** اتصال WebSocket موفق ✅
