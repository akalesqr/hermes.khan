## 🎯 هدف مرحله ۳

تکمیل خان: پنل ادمین کامل، سیستم لایسنس واقعی، لوگو با سیبیل، بیلد ویندوز و تست نهایی همه‌چیز.

---

## ✅ چه چیزهایی ساخته شد

### ۱. پنل مدیریت (Admin Panel)
سه تب کامل در UI:

**👥 تب کاربران:**
- ➕ ساخت کاربر جدید (نام کاربری + نام نمایشی + رمز + نقش)
- 🔃 ارتقا/تنزل سوپروایزر
- 🔑 ریست رمز
- ⏸ فعال/غیرفعال
- 🗑 حذف کاربر

**🎫 تب لایسنس:**
- نمایش وضعیت (🆓 رایگان / ✅ معتبر / ⚠️ جریمه)
- تعداد کاربران مجاز
- نام شرکت + تاریخ انقضا
- **⚠️ هشدار قرمز:** «وارد کردن لایسنس اشتباه محدودیت را به ۵ نفر کاهش می‌دهد»
- انتخاب فایل لایسنس
- دکمه «حذف لایسنس و بازگشت به ۲۰ کاربر»

**🌐 تب شبکه:**
- نوع آدرس (IP/DNS)
- آدرس IP یا DNS
- پورت (۱۷۰۰-۱۷۹۹)
- ذخیره تنظیمات

### ۲. سیستم لایسنس (تست کامل)

| حالت | تست | نتیجه |
|------|------|:-----:|
| بدون لایسنس | ۲۰ کاربر | ✅ ۲۱ام رد شد |
| لایسنس معتبر | ۱۰۰ کاربر | ✅ کاربر ۲۱ام ساخته شد |
| لایسنس دستکاری‌شده | ۱۰۰→۹۹۹ | ✅ رد + جریمه ۵ کاربر |
| حذف لایسنس | بازگشت به ۲۰ | ✅ |

### ۳. لوگو خان با سیبیل 🧔

طراحی SVG اختصاصی:
- 🏠 خانه (گرادیان آبی تلگرامی)
- 🧔 **سیبیل** — امضای خان! (روی خانه مثل صورت)
- پنجره‌ها = چشم‌ها
- در = دهان
- سقف گرد

### ۴. بیلد ویندوز

```bash
GOOS=windows GOARCH=amd64 go build -o khan.exe ./cmd/server
```

| خروجی | حجم |
|-------|-----|
| `khan.exe` (ویندوز) | ~۱۱MB |
| `khan-linux` (لینوکس) | ~۱۱MB |

**همه‌چیز داخل exe:** سرور + دیتابیس + UI + لوگو + کلید عمومی لایسنس
